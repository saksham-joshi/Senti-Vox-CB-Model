# Senti-Vox's Context-Based Model

> ### _Context-based Sentiment Analysis Classification Model of Senti-Vox for English Language._

---

## Directory Structure

The project follows the directory structure shown below:

```text
.
├── dataset/
│   ├── cleaned/
│   └── uncleaned/
├── .gitignore
└── README.md
```

### Directory Overview

| Path                 | Description                                       |
| -------------------- | ------------------------------------------------- |
| `dataset/`           | Contains the project datasets                     |
| `dataset/cleaned/`   | Contains cleaned and processed datasets           |
| `dataset/uncleaned/` | Contains raw or unprocessed datasets              |
| `.gitignore`         | Specifies files and directories excluded from Git |
| `README.md`          | Project documentation                             |
